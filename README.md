# 📌 CommuteFit (커뮤트핏) PRD 초안

> **"CommuteFit은 미세먼지 정보를 단순히 보여주는 서비스가 아니라, 경제적 동기를 활용해 사용자의 출퇴근 행동 변화를 유도하는 서비스이다."**

## 1. 왜 CommuteFit을 기획했는가? (Background Story)

최근 미세먼지와 대기오염 문제는 우리 일상에 직접적인 영향을 주고 있습니다.
뉴스에서는 차량 운행 감소와 대중교통 이용 확대의 필요성을 지속적으로 이야기하지만, 실제로 사람들의 행동을 바꾸기는 쉽지 않습니다.

저는 단순히 미세먼지 수치를 보여주는 서비스보다 **사용자의 실제 행동 변화를 유도할 수 있는 서비스**를 만들고 싶었습니다.
그래서 '환경 보호'라는 사회적 가치와 '출퇴근 비용 절감'이라는 개인의 경제적 가치를 연결하는 방법을 고민했습니다.

CommuteFit은 미세먼지 정보를 단순히 조회하는 서비스가 아닙니다.
미세먼지 데이터와 출퇴근 비용 데이터를 결합하여 사용자가 대중교통 이용의 경제적 이점을 직관적으로 확인하도록 돕고, 이를 통해 친환경적인 이동 선택을 유도하는 서비스입니다.

**사용자 한 명의 작은 이동 선택 변화가 환경 개선에 기여할 수 있다는 믿음**에서 이 기획은 시작되었습니다.

---

## 2. 기획 논리 (Problem - Solution - Differentiation)

### 🚨 문제 (Problem)
고유가 시대에 출퇴근 비용 부담이 나날이 커지고 있습니다.
- 유류비, 주차비, 통행료 등으로 인해 직장인의 고정 지출이 지속적으로 증가하는 상황입니다.

### 💡 해결 (Solution)
자가용과 대중교통의 실제 출퇴근 비용을 직관적으로 비교하여, 사용자에게 **가장 경제적인 출퇴근 방법을 제안**합니다. 

### ⭐ 차별화 (Differentiation)
**미세먼지 데이터를 단순 '날씨 조회용'이 아니라 '출퇴근 의사결정 데이터'로 완벽하게 재해석했습니다.**
미세먼지 API는 서브(Sub) 기능으로 작동하되, 대기질이라는 환경적 요소를 '대중교통 이용'이라는 행동의 명분(Trigger)으로 삼아 사용자의 매일 아침 출퇴근 선택을 돕는 강력한 넛지(Nudge) 도구로 활용됩니다.

---

## 1. 서비스 포지셔닝 및 한 줄 소개

**"출퇴근 비용 절감 행동 유도 서비스 (ESG Habit Maker)"**

단순한 미세먼지 알림 앱이 아닙니다. 미세먼지 정보는 행동을 촉발하는 트리거(Trigger)일 뿐, 서비스의 진짜 핵심은 **'내 돈이 절약되는 과정을 시각화하여 자연스럽게 친환경 출퇴근 습관을 형성하는 것'**입니다. "환경을 지키자"는 막연한 구호 대신, "오늘 18,200원, 이번 달 29만 원을 아낄 수 있다"는 강력한 경제적 혜택을 제공하여 사용자를 움직이게 만듭니다.

---

## 2. 목표

### 1) 출퇴근 비용 절감

사용자가 자가용과 대중교통의 월간 비용 차이를 쉽게 확인할 수 있도록 한다.

### 2) 친환경 이동 유도

미세먼지 경보 시 대중교통 이용을 유도하여 친환경 이동을 장려한다.

### 3) 즉각적인 행동 변화 유도 (돈이 쌓이는 경험)

오늘 자가용 출근 시 드는 총 비용(유류비+주차비+통행료)과 대중교통 비용을 비교하고, 당일 절약 금액(18,200원), 주간 누적(72,800원), 월간 예상(291,200원) 등 **'내 지갑에 돈이 쌓이는 과정'을 명확히 시각화하여** 강력하고 지속적인 행동 변화를 이끌어냅니다.

#### 3. 미세먼지 경보 알림 (UI 표시 상세)

- 에어코리아 API 연동을 통해 실시간 미세먼지/초미세먼지 경보 발령 현황 수신
- **상태별 지정 색상 (Color Scheme):**
  - 🟢 **좋음**: `#10B981` (Emerald Green)
  - 🟡 **보통 (중간)**: `#EAB308` (Yellow)
  - 🔴 **나쁨 / 매우 나쁨**: `#EF4444` (Red)
- **나쁨 (주의보 발령) 시 화면 변화:**
  - 화면 최상단 히어로(Hero) 영역 배경색이 **빨간색 그라데이션**으로 변경
  - 이모지가 마스크를 쓴 이모지(😷)로 변경되며 숨쉬는 듯한 애니메이션 효과 적용
  - 큰 글씨로 **"주의보 발령"** 표시 및 "미세먼지 주의보가 발령되었습니다" 문구 노출
  - 각 측정치(PM10, PM2.5) 옆에 빨간색 뱃지로 수치 경고 표시
  - 하단에 **"건강 수칙"** 영역이 나타나 마스크 착용, 실외 활동 자제 등의 행동 가이드 노출
  - **"오늘은 대기질이 좋지 않습니다. 자가용 이용을 줄이면 배출가스를 줄이는 데 큰 도움이 됩니다."** 메시지를 띄워 강요보다는 부드럽고 설득력 있는 행동 변화 유도
- **보통 (중간) 시 화면 변화:**
  - 배경색이 **노란색 그라데이션**, 이모지(🙂)
  - **"오늘은 대중교통을 이용했으면 좋겠습니다."** 라는 부드러운 권유 메시지 노출
- **매우 나쁨 (경보 발령) 시 화면 변화:**
  - 나쁨 상태와 동일한 **빨간색 그라데이션**, 이모지(🤢), "경보 발령" 뱃지 등으로 한층 더 강한 시각적 경고 제공
- **좋음 (경보 없음) 시 화면 변화:**
  - 배경색이 **초록색 그라데이션**, 이모지(😊), 건강 수칙 영역 숨김 처리

#### 4. 환경 기여도 시각화 (MVP 추가 반영)

- **상세 제공 정보:**
  - **자가용 운행 감소 예상 거리**: 설정된 경로 및 출근일수 기반 왕복 거리 시각화
  - **예상 CO₂ 절감량**: 평균 차량 배출량 데이터를 기준으로 산출
  - **주간 환경 기여도 리포트**: 자가용 대비 대중교통 배출량 비교 분석
  - **누적 환경 기여도 확인**: 대화형 누적 기록 시스템 연동
- **탄소 배출 및 절감량 계산 모델:**
  - **자가용 예상 배출량**: `(거리 * 2 * 출근일수) * 0.185` kg
  - **대중교통 예상 배출량**: `(거리 * 2 * 출근일수) * 0.0275` kg
  - **예상 CO₂ 절감량**: 자가용 배출량 - 대중교통 배출량 = `(거리 * 2 * 출근일수) * 0.1575` kg (예시: 감소 거리 80km 시 절감량 12.6kg 산출)
- **비주얼 그래프 및 넛지 디자인:**
  - 자가용(레드-오렌지) vs 대중교통(민트-에메랄드) 탄소 배출 비교 바 그래프 시각화.
  - 절감량 수치는 하강 화살표(`▼`)와 맥박(`pulse`) 애니메이션으로 강조.
  - 환경적 기여에 대한 행동 유도 메시지와 기상 조건 영향에 따른 안내 문구 상시 노출.
- **누적 기여도 기록 및 애니메이션:**
  - 로컬 스토리지 (`commutefit_cumulative_eco`) 연동을 통한 누적 이용 횟수, 감소 거리, CO₂ 절감량 관리.
  - "기록하기" 버튼 클릭 시 마우스 위치에서 부드럽게 솟아오르며 수치 상승을 피드백해주는 플로팅 토스트 애니메이션 탑재.
- **기획 의도:**
  - 미세먼지 문제는 개인이 완전히 해결할 수 없으나, 개인의 이동수단 선택이 대기질에 미치는 작은 영향을 정량 데이터로 제시하여 지속 가능한 행동 변화를 유도합니다.
  - 경제적 가치(비용 절감)와 환경적 가치(탄소 저감)를 동시에 경험하게 하여 긍정적 넛지(Nudge) 효과를 제공합니다.
- **향후 고도화 계획:**
  - 서울시 교통 데이터 API 실시간 연동
  - 시간대별 교통량 데이터 분석을 통한 정밀 측정
  - 지역별 대기질 변화 분석 연계
  - 실제 교통량 기반 환경 기여도 정밀 계산 모델 구축
  - 전체 사용자 누적 환경 기여도 통계 대시보드 제공

#### 5. 절약 리포트

- 주간/월간 절감 금액
- 누적 절약 현황 제공

#### 6. [Killer Feature] CommuteFit Score (친환경 출퇴근 점수)

단순 비용 계산을 넘어 사용자에게 지속적인 동기를 부여하는 게이미피케이션(Gamification) 핵심 요소입니다.
- **점수화 및 랭킹:** 사용자의 출퇴근 패턴을 분석해 점수로 환산 (예: 이번 주 82점)
- **상대적 성취감:** "서울시 직장인 상위 20%" 같은 그룹 내 비교 지표 제공
- **가치의 시각화:** "올해 누적 42만 원 절약", "소나무 7그루 식재 효과" 등 누적 성과를 한눈에 보여주어 리텐션(재방문율)을 극대화하는 포트폴리오의 확실한 무기입니다.

# 📌 확정된 서비스 정책 (기획 답변)

1. **회원가입:** 회원가입 없이 사용 가능 (로컬 스토리지 기반 데이터 저장)
2. **경로 등록:** 출퇴근 경로 여러 개 등록 가능
3. **유류비 기준:** 평균 휘발유/경유 가격 기준 사용
4. **추가 비용:** 주차비 및 통행료 포함하여 계산
5. **교통 정보:** 실시간 교통정보는 추후 업데이트 (초기엔 평균 거리/시간으로 계산)
6. **알림 기능:** 미세먼지 알림 기능 제공 (API 연동을 통한 화면 내 표시)
7. **서비스 지역:** 서울·경기 수도권 중심으로 시작
8. **절감 리포트:** 주간 기준으로 절감 리포트 제공 (일간/월간은 추후 추가)
9. **경로 추천 API:** 추후 카카오모빌리티 등 도입 예정
10. **이용 여부 확인:** 실제 이용 여부 확인보다 스스로 절감액을 확인하게 하는 행동 유도에 집중
